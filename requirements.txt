#   - Use full `pip install` (no --no-deps) so transitive deps (eth-hash,

#     `urllib3<3,>=2.7.0`. There is NO overlapping version that satisfies
#     both. To use the Lighter exchange, the operator must install
#     `lighter-sdk` manually after the main install (the wizard will
#     report it as "optional, not importable" during install).
#   - The `# private/` prefix is recognized by install.sh as documentation-
#     only — it is NOT passed to `pip install`.
# -----------------------------------------------------------------------------

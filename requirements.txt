# Hermes TradeDesk — required Python dependencies
# -----------------------------------------------------------------------------
# This list mirrors the EXACT runtime on the DigitalOcean reference production
# server (commit 49f8f548). It contains every Python package imported by
# the tradedesk/ agents or the Telegram /trade wizard, except for:
#
#   - stdlib (json, typing, decimal, hashlib, urllib, etc.)
#   - hermes_cli / hermes_agent / plugins.platforms.* (these ship with
#     Hermes itself; not installed by us)
#
# If a pip install is needed at install time, the installer runs
#   python -m pip install -r requirements.txt
# against the existing Hermes venv. We use pip's default dependency
# resolution (no --no-deps) so transitive deps (eth-hash, eth-rlp,
# pycryptodome-via-eth-account, etc.) are correctly installed.
#
# Packages marked `# private/` cannot be installed from PyPI (e.g. they
# are private/edge packages only available on the DigitalOcean server).
# The installer treats them as documentation-only and does not attempt
# to install them. They are NOT required for the wizard to function;
# they are only needed when the operator uses that specific exchange.
# -----------------------------------------------------------------------------
